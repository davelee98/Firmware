# Factory images

Flashable firmware images with a device config built in, one per config in
`configs/`. Generated by `tools/build_factory_image.py` — do not edit or add
images by hand.

```sh
./tools/build_factory_image.py configs/config_Seeed-Studio_reTerminal-E1004.json
```

## Naming

`factory_[Manufacturer Name]_[Model Name]_[firmware version]` plus a suffix.
The `factory_` prefix matches the `config_` prefix of the config it was built
from — `configs/config_Seeed-Studio_reTerminal-E1004.json` becomes
`factory_Seeed-Studio_reTerminal-E1004_2.26.7_full.bin`:

| Suffix | Target | Flash |
|---|---|---|
| `_full.bin` | ESP32 — bootloader, partitions and app merged | `esptool.py write-flash 0x0 <file>` |
| `.uf2` | nRF52840 | copy onto the bootloader drive (double-tap reset) |
| `.hex` | nRF52840 | SWD / J-Link, alongside the `.uf2` |

The env is the one `configs/firmware_targets.json` maps the config to.

ESP32 `_full.bin` images are git-ignored and never committed: rebuild one from
its config with the command above. Only nRF `.uf2` / `.hex` images are tracked.

## Keeping it current

Rebuild an image whenever its config changes or a new firmware version is
released. A rebuild removes that config's previous image, so this directory
only ever holds the current image for each config.

The built-in config is applied only when the device has no valid stored
config, so erase flash first on a device that has been used.
